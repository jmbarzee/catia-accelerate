# Shortcuts

Defaults for CATIA V5. Tools > Customize > Commands lets you add your own; the Commands
tab shows the current binding for each command.

## Keyboard

| Keys | Action |
|---|---|
| Esc | Cancel current command |
| F1 | Help on the current command |
| F3 | Show or hide the spec tree |
| Shift+F3 | Toggle zoom/pan between tree and 3D viewer |
| Alt+Enter | Properties of selection |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Ctrl+S | Save |
| Ctrl+U | Update |
| Ctrl+F | Edit > Search |
| Ctrl+A | Select all (in the active object) |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut, copy, paste |
| Ctrl+PgUp / Ctrl+PgDn | Zoom in / out |
| Arrow keys | Pan |
| Shift+Arrow keys | Rotate |
| Alt+F8 | Tools > Macro > Macros |
| Alt+F11 | VBA editor |
| Ctrl+Tab | Cycle open windows |
| Delete | Delete selection |

## Mouse

| Buttons | Action |
|---|---|
| Middle drag | Pan |
| Middle + Left (hold both) drag | Rotate |
| Middle, click Left once, drag | Zoom |
| Left click | Select |
| Ctrl + Left click | Add to selection |
| Left drag in empty space | Trap selection (box) |
| Right click | Context menu for the object under the cursor |
| Double-click a tree node | Activate it (enter edit) |
| Double-click a toolbar icon | Keep the command active for repeated use |

## Selection tricks

- Click once, then hover: objects under the cursor get a preselection outline. Use the
  up/down arrow keys while hovering to cycle through overlapping candidates, then click.
- Trap selection with the Selection toolbar's arrow: trap, intersecting trap, polygon trap.
- **Selection sets**: Edit > Selection Sets. Name a selection, recall it later.
- **Filter by type**: Edit > Search, or the User Selection Filter toolbar (View > Toolbars).

## Add your own

Common additions people make at Tools > Customize > Commands: Fit All In, Hide/Show,
Reframe On, Design Mode, Visualization Mode. Record the bindings you add in
`company/conventions.md` so the team shares them.
