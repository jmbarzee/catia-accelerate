# Glossary

| Term | Meaning |
|---|---|
| **3DEXPERIENCE (3DX, V6)** | Dassault's successor platform. Database-backed, no files on disk. Different large-assembly story. |
| **Activate / Deactivate node** | Load or unload a branch of a product. Saved with the product. |
| **Active object** | The node you are editing. Underlined in the tree. Double-click to change. |
| **Body / PartBody** | Container for solid features inside a part. PartBody is the main one. |
| **CATScript** | VBScript-based macro language. Plain text files, no IDE, runs on any CATIA. |
| **CATVBA** | Full VBA with IDE and IntelliSense. Projects stored as `.catvba`. Needs the VBA option installed. |
| **CATSettings** | Per-user settings files in `%APPDATA%\DassaultSystemes\CATSettings`. |
| **CGR** | CATIA Graphical Representation. A lightweight tessellated copy of a part used in Visualization Mode. Lives in the cache. |
| **Compass** | The axis widget at top right. Drag onto a part to move it. |
| **Constraint** | Assembly relation (coincidence, contact, offset, angle, fix) or sketch relation. |
| **Contextual link** | A part feature that references geometry in another part. Binds the part to that assembly. |
| **Design Mode** | Full part data loaded. Editable. Heavy. |
| **DMU** | Digital Mock-Up workbenches: Navigator, Space Analysis (clash, section), Kinematics, Fitting. |
| **ENOVIA / Windchill / Teamcenter** | PLM systems. If your site uses one, saving goes through it, not File > Save. |
| **Feature** | One step in a part's history: pad, pocket, fillet, sketch. |
| **Geometrical Set** | Container for surfaces, wireframe, points, planes. Not solids. |
| **GSD** | Generative Shape Design, the surfacing workbench. |
| **Instance** | One placement of a reference part in an assembly. Many instances, one part number. |
| **Knowledgeware** | Parameters, formulas, rules, design tables. The `f(x)` icon. |
| **Part number** | The identity of a part or product. In PLM sites, assigned by the PLM system. |
| **Product** | An assembly document (`.CATProduct`). References, does not contain, its children. |
| **Publication** | A named, stable reference to a face, plane, axis, or point on a part. |
| **Reframe On** | Zoom the viewer to a selected object. |
| **Selective Load** | Opening a product structure without geometry, then loading branches on demand. |
| **Skeleton** | A part holding only reference geometry that other parts build on. Common in large-assembly design methods. |
| **Spec tree** | Specification tree. The left panel. |
| **Update** | Recompute geometry after a change. Ctrl+U. Red features need it. |
| **Visualization Mode** | Lightweight CGR shell loaded. Not editable. Fast. |
| **Workbench** | A toolset (Part Design, Assembly Design, Drafting, GSD). Icon at top right. |
| **Work object** | The body or set new features go into. Right-click > Define In Work Object. |
